Flying study kit

Interactive tools and notes for private pilot knowledge—density altitude, lift theory, performance, and drill quizzes—anchored to MIT OCW 16.687 and the FAA Pilot’s Handbook of Aeronautical Knowledge.

Educational use only — not for flight planning. Always use the AFM/POH for the airplane you fly and current FAA materials on faa.gov.

FAA handbooks (official)

Free U.S. government publications. Prefer the current edition on faa.gov. Large PDFs are not hosted on this Pages site (GitHub size limits); download from the FAA or clone the repo and run the download script.

  • Pilot’s Handbook of Aeronautical Knowledge (FAA-H-8083-25C) — Ch. 4 principles / density; Ch. 11 performance
  • Airplane Flying Handbook (FAA-H-8083-3C)

How to use this site

  1. Read density altitude, altitude math, Bernoulli, and AOA / stall / load factor notes.
  2. Open the Performance, Lift Theory, and AOA labs.
  3. Drill with the quiz.
  4. Cross-check claims in the PHAK chapters above.

Repository

Source, scripts, and optional offline OCW dump live in the GitHub repo. Local clone can also hold handbook PDFs via python3 scripts/download_faa_handbooks.py.
